# Métricas de Tráfego Pago

Script em Python que calcula CTR, CPC, CPA e ROAS a partir dos números de uma campanha.

## Por que fiz

Trabalho com gestão de tráfego e quis automatizar o cálculo dessas métricas, aplicando Python a um problema real do meu dia a dia.

## Como rodar

1. Instale o Python 3
2. Baixe o arquivo `metricas.py`
3. No terminal, rode: `python metricas.py`

## Exemplo

Investimento 600, impressões 40000, cliques 800, conversões 20 e receita 2500 resultam em:

- CTR: 2.00%
- CPC: R$ 0.75
- CPA: R$ 30.00
- ROAS: 4.17
